# homebrew-tap

```sh
brew tap juliendeveaux/tap
```

## Casks

### `glance-ranokay`

[Glance](https://github.com/ranokay/glance), the all-in-one Quick Look plugin, built from
[ranokay's fork](https://github.com/ranokay/glance) of
[chamburr/glance](https://github.com/chamburr/glance)

```sh
brew install --cask glance-ranokay
```
